# The jstack guide

A numbered walkthrough for a first real task, not a feature list. Each page teaches by pasting an
actual prompt and narrating what happens to it — the skill catalog and `docs/index.html` are the
reference for "what exists"; this is "what order to learn it in."

1. [Setup](./01-setup.md) — get `jstack.config.json` in place, the fast way.
2. [Your first task](./02-first-task.md) — invoke one real skill end to end.
3. [Routing and config](./03-routing-and-config.md) — how a free-text ask picks a skill, and where org values actually live.
4. [Multi-lens review](./04-multi-lens-review.md) — get CEO/PM/engineer/QA/designer/security pushback on one artifact.
5. [Verify and evals](./05-verify-and-evals.md) — `bun run check`, and the cross-model regression harness.
6. [Recipes and pitfalls](./06-recipes-and-pitfalls.md) — copy-paste prompts, and the mistake everyone makes once.

Each page ends with a **Pitfall** — the mistake this page exists to prevent — and a **Next** link.
