Overview

This page is a static, searchable catalog of every SKILL.md shipped in this plugin—similar to SDK reference documentation. Use the search box to filter and highlight matches; use the category list to narrow the list. Click a skill’s title row to expand full Markdown (examples, customization, workflows)—loaded from the repo on first open. Primary-click a .md link for an in-page preview; use Cmd/Ctrl-click or Open file in the panel to open the raw source in a new tab.

After skill changes: run bun run docs:generate, then bun run docs:serve — the server uses the package root so ./README.md and ./skills/… links resolve. After bun run docs:build, / serves the single-file catalog (also in docs/index.html for GitHub Pages). One command: bun run docs:preview.

Setup guide

Use this page to get from zero → working jstack.core: required team config, optional integrations (Jira, Slack, Notion, GBrain, MCP), validation, and where to look when something is missing. Prefer the skill or CLI wizard first; drop to manual files when you need full control or automation.

Required baseline

  • Install the plugin for your host (Claude Code, Cursor, or Codex) — see the README installation section.
  • jstack.config.json at your project root (team name, timezone, and whatever integrations you enable). The wizard creates this; defaults live in config/defaults.json.
  • After changes, run jstack doctor (and --strict in CI or when you want GBrain / knowledge paths to be hard requirements).

Easy path — skill (in chat)

In an agent session, invoke the setup skill so the model walks onboarding using repo conventions (no secrets pasted into chat — use env / secret stores).

  • jstack:setup / skill jstack-setup First-time wizard, config creation, pointers to jstack doctor. Entry: skills/setup/SKILL.md.
  • jstack:init-session (session init) After install, when you start real jstack work: GBrain target, session id. See README “Session lifecycle”.

Easy path — CLI (terminal)

From a clone of this repo, the CLI lives under cli/. Examples (adjust /path/to/jstack.core): 

cd /path/to/jstack.core
bun install --cwd cli

# Interactive wizard — team, timezone, optional Jira, telemetry, MCP merge from .mcp.json
./cli/bin/jstack setup

# Same wizard but always include GBrain + knowledge_storage / knowledge_base prompts
./cli/bin/jstack setup --with-gbrain-kb

# Validate config and layout (warnings by default)
./cli/bin/jstack doctor
./cli/bin/jstack doctor --strict

# Explore other commands
./cli/bin/jstack --help
./cli/bin/jstack --help-json

Tip: If your monorepo root is the parent of jstack.core/, run the CLI from jstack.core and point docs at the plugin root — see README Monorepo note at the top.

Advanced — open and edit yourself

When you already know the shape of config or need to script edits, copy templates and edit in your editor. Re-run jstack doctor after changes. 

# Team config from template (from repo root or plugin root)
cp /path/to/jstack.core/config/defaults.json ./jstack.config.json
# Optional personal overlay (path may vary by host; see config-team-vs-personal.md)
cp /path/to/jstack.core/config/personal.example.json ~/.config/jstack/jstack.personal.json
  • Edit jstack.config.json — follow config-schema.md and PE_AND_TEAM_CONFIG.md.
  • Wire hosts & MCP — integration-guide.md.
  • Skill authoring — skill-conventions.md and skill-creator.
